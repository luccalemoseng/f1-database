# Roadmap

## Phase 2 · Season scoring and the ML dataset ✅

Done. See *Phase 2 · Season dataset*. Possible extensions: results-only history
from 1950 (Jolpica API) and practice-session long-run pace as extra features.

## Phase 3 · Analysis ✅

Done. See *Phase 3 · Analysis*. Ideas: fuel effect measured per track instead
of a fixed 0.03 s/kg, pit-stop time loss, undercut and overcut detection.

## Phase 4 · Live timing ✅

Done. See *Phase 4 · Live timing*. Ideas: live gap charts, live tyre
degradation, notifications on flags.

## Hosting

A static version on GitHub Pages is possible: pre-computed JSON for the Season,
Analysis and Compare pages, rebuilt by GitHub Actions after every race weekend.
Live timing needs a small always-on server.

## Visual: F1 car models ✅

Done: one parametric isometric car per regulation era, on the Season page
(*The car figure*). Possible extensions: an exploded view of the systems
(power unit, suspension, floor) and more detailed per-team liveries.
